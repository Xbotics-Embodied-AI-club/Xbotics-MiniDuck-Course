# 装配总览

整只小鸭子按模块装：先装右腿、左腿和胯部，把腿接到胯上并装好电池与电源板，再装脖子和头部，最后用两片肩壳合在一起。先看全部部件，再看各个模块怎样拼成整只。

## 装配顺序

<video class="anim" controls preload="metadata" poster="../_static/assembly/flow.jpg" src="../_static/assembly/flow.mp4"></video>

装之前先做[准备](prep.md)：15 颗舵机编号、转到中位，拆辅助舵盘。然后按动画里的顺序装：

| 顺序 | 章节 | 装什么 |
| --- | --- | --- |
| 1 | [右腿](right-leg.md) | 1、2、3 号舵机，小腿、脚、大腿 |
| 2 | [左腿](left-leg.md) | 6、7、8 号舵机，与右腿对称 |
| 3 | [胯部](hip.md) | 4、5、9、10 号舵机，胯板与舵机架 |
| 4 | [接腿与电源](legs-on.md) | 两条腿接到胯上，电池背板、电源板、两节电池 |
| 5 | [脖子](neck.md) | 11、12、13、14 号舵机 |
| 6 | [头部](head.md) | 15 号舵机（嘴）、脸板与头壳 |
| 7 | [肩壳合装](finish.md) | 两片肩壳夹住胯，嵌入脖子 |

螺丝几乎全是 M2×6 自攻螺丝（共 131 颗），接腿与电源一章另用两颗 M3×16。各章表里螺丝一列只写数字的都是 M2×6 自攻螺丝；加粗的是接线：线要在挡住它的零件装上之前接好。
