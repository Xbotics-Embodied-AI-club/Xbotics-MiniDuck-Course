# 版本与更新

仓库、硬件、固件和策略各有版本号，它们的对应关系只声明在一处：仓库根目录的 `versions.toml`。

| 什么 | 版本号怎么写 | 规则 |
| --- | --- | --- |
| 手册与代码 | `v<日期>.<序号>` | 一次发布一个标签，发布后不再改动 |
| 硬件 | `<日期>-<舵机>` | 硬件变了就加一个新版本；策略与固件档案用同一个版本号 |
| 固件 | `主.次.修订` | 网页顶部显示的就是这个数 |

## 怎么对照

连上小鸭子的热点，打开文件页 `http://192.168.4.1:83`，顶部写着硬件版本和固件版本，和下面的当前版本对照。
